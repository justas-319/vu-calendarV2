# VU Calendar v2

## User stroies

1. As a user i want to see up to date timetables so that i can plan my courses.
2. As a user i want to be able to pick my main course.
3. As a user i want to be able to pick from all available modules.
4. As a user i want to see if the picked course and modules time table overlap so i can pick modules i can attend.
5. As a user i want to have a search bar to search for a specific course.
6. As a user i want to have a search bar to search for a specific module.
7. As a user i want to be able to filter courses and modules by faculties.
8. As a user i want to see what modules are not overlaping with my main course.
9. As a user i want to export my calendar to use it in my calendar app.
10. As a user i want to login to save my calendar.
